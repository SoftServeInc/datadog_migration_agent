# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [1.0.0] - first public release

### Added
- One-command OpenTelemetry Demo deployment (`run.sh`) with a single collector exporting to
  Datadog, Splunk Observability Cloud, Splunk Enterprise and Splunk Agent Observability.
- Error-injection profiles (flagd), continuous k6 load and GenAI traffic replay.
- Observability migration skills (assessment, planning, detector, SLO and dashboard
  executors, security review) for Codex, with deterministic Python cores
  and a local MCP approval server.
- Open-source project files: CONTRIBUTING, SECURITY, CODE_OF_CONDUCT, MAINTAINERS, NOTICE,
  third-party notices, CI, Dependabot and issue/PR templates.
